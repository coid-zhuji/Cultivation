# 修仙模拟器 - 像素素材资源库

> 本目录用于存放游戏所需的像素图形资源文件
>
> **授权**: 所有素材均为CC0协议，可免费商用

## 目录结构

```
像素素材库/
├── 角色/              # 角色立绘、头像、动画帧
│   ├── 人物/          # 角色素材
│   └── 怪物/          # 怪物敌人
├── 场景/              # 地图、背景、装饰
│   ├── 地形/          # 地形瓷砖
│   ├── 建筑/          # 建筑场景
│   └── 地牢/          # 地牢元素
├── 道具/              # 丹药、法宝、灵石等
│   ├── 装备/          # 武器装备
│   └── 灵石/          # 灵石货币
├── UI元素/            # 按钮、面板、图标
│   ├── 按钮/          # 按钮素材
│   └── 面板/          # 面板窗口
├── 特效/              # 修炼、突破、攻击特效
│   └── 粒子/          # 粒子特效(Kenney)
├── 功法图标/          # 功法分类图标
└── 境界标识/          # 境界等级标识
```

## 自行生成像素素材

如需自定义素材，可使用以下工具：

| 工具 | 平台 | 特点 |
|------|------|------|
| Aseprite | Win/Mac/Linux | 专业像素画工具 |
| Piskel | 在线 | 免费，简单易用 |
| Lospec Palette | 在线 | 像素调色参考 |
| Pixel Art Editor | 在线 | 轻量级编辑器 |

---

## 获取方式

1. **下载免费素材**: 访问上述推荐网站下载CC0素材
2. **自定义绘制**: 使用Aseprite等工具自行绘制
3. **AI生成**: 使用Midjourney等AI工具生成后手工优化

获取素材后，将文件放入对应目录即可。

---

## 使用说明

下载或制作素材后:
1. 将PNG/SVG文件放入对应分类目录
2. ZIP包可直接放入对应目录，需要时解压
3. 建议保持16x16或32x32像素的标准尺寸
